# NothingLess — Quickshell Desktop Shell

> Proyecto de **Leriart** — fork mejorado de Ambxst enfocado en Hyprland.
> Reddit: https://www.reddit.com/r/hyprland/s/Ki1vXha5Jg
> GitHub: https://github.com/leriart/NothingLess

## Características principales

- **Overlay de métricas y FPS** en el notch para videojuegos
- **QTMultimedia** para fondos animados
- **Barra dinámica** como preset principal
- **Monitor manager** integrado en el mismo shell
- Múltiples ajustes de rendimiento
- Bugs corregidos respecto a Ambxst original
- Funciones enfocadas **solo en Hyprland** (se descartó soporte para otros compositores)

## Proyecto relacionado: cava-bg

El autor también creó **cava-bg** — fondo con barras animadas independiente que funciona con cualquier compositor Wayland. Se puede combinar con NothingLess.

## Notas del autor

- No usa dotfiles como tal — usa configuración básica con parámetros para NVIDIA
- El shell mismo ya trae ajustes de pantallas, animaciones, bordes, etc.
- El único requisito base es CachyOS (o cualquier distro con Hyprland + Quickshell)
- NothingLess incluye todos los layouts de Ambxst más los nuevos que creó
