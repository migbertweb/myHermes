# Brand Register

Focus: marketing, landing pages, portfolios, campaigns.

## Anti-patterns
- Inter/system-ui as default brand font without custom identity.
- Purple-to-blue gradients.
- Icon tile repeated above every heading.
- Card soup / nested cards.
- Gray text on colored backgrounds.

## Priorities
- Typography contrast: headline + body must read as one voice.
- Whitespace as rhythm, not padding randomly distributed.
- Motion as punctuation, not decoration.
- Color as signal, not atmosphere.

## Checklist
- Single display family + single body family. Contrast axis preferred.
- Display H1 letter-spacing >= -0.04em.
- Hero clamp max <= 6rem.
- `text-wrap: balance` on h1–h3.
- Placeholder contrast >= 4.5:1.
