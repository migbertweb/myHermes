# Init

Flow:
1. Ask user: brand or product surface?
2. If brand: audience, product lane, voice, anti-references, colors, type, components.
3. If product: audience, primary workflows, density preference, theming constraints.
4. Write `PRODUCT.md` at project root.
5. Offer `DESIGN.md` when design context is substantial.
6. Recommend next command: `/impeccable shape` for blank-slate, `/impeccable audit` for existing UI.
