# Register

Choose register by first match:
1. Task cue: branding/marketing/landing/portfolio/campaign → `brand`
2. Surface in focus: app UI/admin/dashboard/tool → `product`
3. `register` field in `PRODUCT.md` if present.

## brand
- Design IS the product.
- Hierarchy: emotion → clarity → conversion.
- Prioritize: typography, whitespace, motion, color psychology.
- Anti-patterns: Inter default, purple gradients, card soup, gray-on-color text.

## product
- Design SERVES the product.
- Prioritize: density, clarity, feedback, edge states, accessibility.
- Anti-patterns: over-styled chrome, decorative motion breaking focus, decorative color causing contrast failure.
