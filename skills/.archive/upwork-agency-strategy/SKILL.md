# Upwork Agency Setup & Strategy

This skill governs the creation and positioning of specialized agency profiles on Upwork, specifically for transitioning from a generalist freelancer to a niche-focused agency owner.

## Workflow

1. **Niche Definition**: Identify a high-demand, IA-augmented service class (e.g., AI Marketing, AI Automation) that complements but doesn't overlap with the primary freelancer profile.
2. **Branding**: Develop a "premium-tech" name and a value proposition focusing on efficiency/cost-reduction via AI.
3. **Multilingual Optimization**: Create core assets (Title, Bio, Portfolio) in the target languages (typically EN, ES, PT for LATAM/Global markets).
4. **Portfolio Engineering**: Construct specific, data-driven portfolio entries.
    - Use the format: `Title` $\rightarrow$ `Role` $\rightarrow$ `Description (with metrics)` $\rightarrow$ `Skills`.
    - Ensure descriptions fit within Upwork's character limits (approx 600 chars).
5. **Skills Mapping**: Select a mix of "Umbrella" skills (e.g., Marketing Automation) and "Tool-specific" skills (e.g., GPT, ElevenLabs).
6. **Pricing Matrix**: Define Entry, Standard, and Premium tiers based on market rates, emphasizing the "Value Gap" (Agency Traditional vs. AI-Driven cost).

## Pitfalls & Guidelines

- **Anti-Pattern: Multiple Accounts**: NEVER create a second Upwork account. Use the "Agency" feature within a single account to avoid permanent bans.
- **Skill Dilution**: Do not list general development skills (e.g., React, Node.js) on an agency profile dedicated to Marketing. This attracts the wrong client type.
- **Pricing Psychology**: Set an hourly rate as a reference ($35-50/hr), but always pitch Fixed-Price or Retainer models in proposals to maximize LTV.
- **Review Bootstrapping**: For the first 3-5 clients, offer "Entry" tier pricing with a 20% discount explicitly tied to a high-quality review.

## Verification

- [ ] Bio fits within Upwork character limits.
- [ ] Portfolio entries have quantifiable results (e.g., "340+ qualified leads").
- [ ] Profile contains no "dev-heavy" keywords that distract from the agency niche.
